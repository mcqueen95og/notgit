# notgit

**A dead-simple, beginner-friendly version control tool.**

notgit lets you snapshot your project, view history, and revert changes — without learning Git.

## Commands

- `notgit init` — Initialize notgit in the current directory
- `notgit save "message"` — Save a snapshot of the current directory
- `notgit history` — List all saved snapshots
- `notgit undo` — Revert current directory to the latest saved snapshot

## Why notgit?

Git has a steep learning curve. notgit gives you the core idea — save your progress, revert when things break — with three commands.
